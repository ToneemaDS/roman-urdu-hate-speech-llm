# Data

The dataset was provided by Dr. Hafiz Hassaan Saeed for this research. It is not publicly available, so it is not included in this repository. Place the files here before running the notebooks:

| File | Used by | Contents |
|---|---|---|
| `PURRUTT.xlsx` | all notebooks | 72,771 social media comments with columns `Comment` (Roman Urdu text), `Toxic` (1 = hate speech / offensive, 0 = not) and `Urdu` (Urdu-script transliteration). About 18% of comments are toxic. |
| `special_examples.csv` | prompt engineering and prompt tuning | A small set of curated labelled comments (`Comment`, `Toxic`) used as few-shot examples. |

> **Content warning:** the dataset contains offensive and hateful language, collected for research on detecting it.
